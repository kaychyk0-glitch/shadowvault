# ShadowVault — невидимое зашифрованное хранилище изображений

## Как это работает

| Что требуется | Реализация |
|---|---|
| Приложение невидимо | Иконка удаляется из лаунчера после первого запуска (`setComponentEnabledSetting`) |
| Секретный вход | Код набора `*#*#4263#*#*` в приложении «Телефон» → невидимый TriggerActivity → чёрный экран-прикрытие |
| Секретный жест | Рисуется на чёрном экране при первом запуске (дважды). Проверка — ресемплинг в 64 точки + нормализация, порог среднего расстояния |
| Невозможно найти на устройстве | `filesDir` (недоступен другим приложениям) + шифрование AES-256-GCM + разрезание на 128 КБ-куски со случайными именами без расширений в случайных подкаталогах `.sys/xx/yy/` |
| Индекс | Зашифрованный JSON, имя файла случайное и хранится только в приватных SharedPreferences |
| Ключ | Android Keystore, 256 бит, не покидает TEE/StrongBox, не извлекаем даже с root |
| Показ | Расшифровка только в памяти процесса, расшифрованный файл на диске никогда не существует |

## Сценарий

1. Установить APK. Иконка «MediaService» появится один раз.
2. Открыть → нарисовать секретный жест дважды → иконка скроется, откроется хранилище.
3. «+ Добавить изображение» → Photo Picker → импорт.
4. Выйти. Приложения нет ни в меню, ни в списке видимых.
5. Вход: Телефон → `*#*#4263#*#*` → нарисовать жест на чёрном экране → хранилище.

## Защита от перебора

10 неверных жестов подряд → вход блокируется на 30 секунд, экран-прикрытие закрывается.

## Важно знать (честные ограничения Android)

- **Оригинал картинки.** Photo Picker копирует файл, исходник остаётся в галерее. Его нужно удалить вручную — иначе смысл теряется. (Вариант: добавить захват камеры напрямую в хранилище.)
- **Жест поверх чужих приложений** невозможен без root — Android запрещает перехват касаний по экрану. Поэтому жест рисуется на собственном чёрном экране-прикрытии, который не выглядит как хранилище.
- **Секретный код `*#*#…#*#*`** поддерживают стоковые дайлеры Google/Pixel/Samsung и большинство OEM-оболочек. Если на устройстве код не срабатывает — вернуть иконку через ADB:
  `adb shell pm enable com.shadowvault.app/.CoverActivity`
- **Жест — не пароль.** Жест из 64 точек даёт ~30–40 бит энтропии против брутфорса по образцу на экране (отпечатки пальцев/следы). Для параноидальной защиты добавить биометрию (`setUserAuthenticationRequired(true)` + BiometricPrompt).
- **Обновление Android / очистка данных** удалит хранилище безвозвратно (ключ Keystore сотрётся). Резервное копирование отключено (`allowBackup=false`) осознанно.
- **Форензика.** Удалённые куски не перезаписываются (flash + FTL). Для гарантированного затирания нужен root + перезапись свободного места.

## Сборка

Открыть папку в Android Studio (Giraffe+), дождаться синхронизации Gradle, Build → Build APK. minSdk 26, targetSdk 34.
